# Security

OpenCallMesh is experimental. Keep Controller and Agents on a trusted LAN/VPN; do not expose ports publicly. Authentication, TLS/mTLS and encrypted media are required before WAN operation. Never commit secrets, Telegram sessions, OTPs, phone numbers, API IDs/hashes, tokens, private keys or recordings.

The operator is responsible for authorization and consent to bridge voice rooms. Recording and transcription are disabled by design.
